## Ordering

`updatedAt` records the repository API `pushed_at` value checked on 2026-09-10. Entries sort by the complete timestamp descending, including within a single date. These are update dates, not original project creation dates. Refresh the timestamps in `projects.js` when updating project content; the public page does not call GitHub on every visit.
